# Sistema Gestor de Exposições - SESC 2026

Aplicação de gestão estratégica para o portfólio de exposições, integrada com Supabase para persistência de dados.

## Funcionalidades
- **Visão Geral:** KPIs de orçamento, carga de trabalho por assistente e equilíbrio regional.
- **Timeline:** Visualização estilo Gantt das ocupações por unidade.
- **Controle de Aberturas:** Calendário mensal de lançamentos e controle de tarefas.
- **Segurança (RBAC):** Níveis de acesso diferenciados para Admin, Consultor e Secretaria.

## Tecnologias
- HTML / CSS / JavaScript (Vanilla)
- Supabase (Backend as a Service)
- GitHub Pages (Hospedagem)
